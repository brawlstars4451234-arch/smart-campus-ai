# Smart Campus AI — учебный прототип

Демонстрационная информационная система управления кампусом. Проект сделан на HTML5, CSS3 и JavaScript, использует localStorage и Chart.js. Данные датчиков синтетические; AI-модуль основан на порогах и простых статистических правилах, без внешнего AI API.

## Запуск
1. Распакуйте архив.
2. Откройте папку в VS Code.
3. Запустите `index.html` через Live Server (рекомендуется).
4. На странице входа укажите имя и роль. Данные хранятся локально в браузере.

## Страницы
- `index.html` — учебная форма входа.
- `dashboard.html` — KPI, энергопотребление и состояние кампуса.
- `rooms.html` — поиск и фильтрация помещений.
- `devices.html` — устройства и статусы.
- `incidents.html` — создание, редактирование, удаление и изменение статуса заявок.
- `analytics.html` — пороговый анализ, рекомендации и графики.
- `notifications.html` — предупреждения.
- `settings.html` — темы, параметры и сброс тестовых данных.

## Публикация на GitHub Pages
Загрузите содержимое папки в репозиторий. В Settings → Pages выберите Deploy from a branch, ветку `main`, папку `/(root)`. После сохранения дождитесь публикации.

> Это учебный прототип, не предназначенный для реального управления зданием или хранения конфиденциальных данных.
